Tic-Tac-Toe

A simple, fully functional two-player Tic-Tac-Toe game built using only:

HTML

CSS

JavaScript

No frameworks, libraries, or external dependencies are required.

Project Structure
tic-tac-toe/
├── index.html
├── style.css
├── script.js
└── README.md

Features

Two-player gameplay

Players alternate between X and O

Automatic win detection

Automatic draw detection

Winning cells are highlighted

Restart button

Responsive design for desktop and mobile screens

No external dependencies

How to Run

Download or copy the four project files into the same folder.

Open index.html in any modern web browser.

The game is ready to play.

No installation, build process, or local server is required.

How to Play

Player X starts the game.

Click any empty square to place your mark.

Player O takes the next turn.

Continue taking turns.

The first player to get three marks in a row horizontally, vertically, or diagonally wins.

If all nine squares are filled without a winner, the game ends in a draw.

Click Restart Game to start a new round.
